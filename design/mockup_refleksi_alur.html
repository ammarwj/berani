📝 Catatan untuk Developer:
Logika IF-THEN:
IF perasaan = Sangat Baik / Baik / Biasa
→ THEN tampilkan Jalur A (2 tahap)

IF perasaan = Cemas / Tertekan
→ THEN tampilkan Jalur B (4 tahap)
Catatan privasi:
• Tulisan di Tahap 1 & 2B → hanya tersimpan di device siswa (tidak dikirim ke server)
• Laporan bullying → dikirim ke dashboard Guru BK
• Pilihan perasaan → tidak terlihat oleh Guru BK
